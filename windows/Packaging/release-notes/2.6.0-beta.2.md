## NetFluss for Windows — Beta 2

The second public beta of NetFluss for Windows. It is mostly about **staying put**: thanks to the first testers, NetFluss now runs on PCs where Beta 1 could quietly disappear from the taskbar after a while.

> **On a Mac?** Nothing changes for you. This release is for Windows only.

---

## What's new in Beta 2

- **One program file** — NetFluss is now a single `NetFluss.exe`. Beta 1 shipped its code as many separate files, and Windows' **Smart App Control** could block one of them minutes after NetFluss had started, which ended the app. The only other files are Microsoft's own, signed libraries.
- **No more vanishing on sleep** — saving the statistics and the Traffic Timer as the PC went to sleep could end NetFluss. It no longer can.
- **If NetFluss ever quits unexpectedly**, the next start tells you so and keeps what Windows recorded about it. Click the notification to see it — and please include it in a report, it usually names the exact cause.
- **Easier to find on first launch** — NetFluss says where it is running and opens its popover there. Windows hides new icons behind the **^** next to the clock, which made the app look like it had quit.
- **Clearer helper messages** — if the helper is newer than the app, NetFluss now says so instead of calling the helper "out of date".
- **Quieter when quitting** — closing or updating NetFluss no longer logs errors while it shuts down.

### Updating from Beta 1

The installed Beta 1 offers this update by itself (**About → Install and Relaunch**). Because the helper belongs to each version, Top Apps then asks you to **update the helper** once — Windows asks for administrator approval.

### "Windows protected your PC"

This beta is **not yet code-signed for Windows**, so SmartScreen warns the first time you run the installer. Click **More info → Run anyway**.

If your PC has **Smart App Control** turned on, Windows blocks unsigned apps completely and the beta will not start. Signed builds will follow in a later release.

To check a download, compare it with `SHA256SUMS.txt` (`certutil -hashfile <file> SHA256`). That list is signed (`SHA256SUMS.txt.sig`) — the in-app updater checks the signature before installing anything.

## What's in it

- **Live rates where you want them** — on the taskbar next to the clock, in the notification area, or in a floating widget you can place anywhere. One line, two lines, total, or the **Dashboard** styles with a ring gauge.
- **The popover** — totals, your adapters (rename, reorder, hide), your network path from PC to router to internet, the **DNS switcher**, a **Wi-Fi** switcher, **Top Apps**, **Data Usage**, the **Traffic Timer**, your **router** and your **VPN**. Reorder or hide sections, pin it as a window, and resize it.
- **Bandwidth Statistics** — from the last hour to the last year, or any custom range.
- **Speed Test** — Cloudflare or M-Lab, with a history you can annotate.
- **Network Slice** — which app talks to which server, live.
- **Routers** — Fritz!Box, UniFi, OpenWRT and OPNsense, with credentials kept in Windows Credential Manager.
- **VPN client** — import OpenVPN and WireGuard profiles (a file, a folder or a provider's zip), or use Windows' own IKEv2 connections. Auto-reconnect, connect at launch and a DNS preset while connected.
- **VPN indicator** — a dot or shield next to your rates shows when any VPN is active, from NetFluss or any other app (**Preferences → Taskbar**), optionally with your exit country.
- **English, German, Simplified and Traditional Chinese.**

### Optional extras

NetFluss offers these where you need them:

- **The NetFluss helper** (*Preferences → General*) — Windows only lets administrators see which app uses the network, so **Top Apps** and **Network Slice** need it. It also switches DNS without asking each time and runs OpenVPN and WireGuard connections. Installing it asks for administrator approval once.
- **OpenVPN Community** and **WireGuard for Windows** — for VPN profiles of those kinds.

## Updates

The installed version **keeps itself up to date**: it checks once a day, and **About → Install and Relaunch** downloads, verifies and installs the update. As a beta tester you get the next beta, and then the final release. The portable version is updated by hand.

---

## Good to know

- **Taskbar placement** — Windows has no official way for apps to put text on the taskbar, so this is best effort. If a Windows update moves things around, NetFluss falls back to the notification area; the floating widget always works.
- **VPN** — WireGuard and Windows IKEv2 connections have been tested end to end. OpenVPN has been tested up to the connection to the server; reports from real OpenVPN servers are especially welcome.
- **Uninstalling** — *Settings → Apps → NetFluss*. If you installed the helper, Windows asks for administrator approval to remove it too.
